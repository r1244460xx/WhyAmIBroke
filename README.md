# 💳 信用卡帳單分析報表 (Credit Card Statement Analysis Dashboard)

基於 **Python + Streamlit + Plotly** 開發的現代化信用卡帳單分析可視化工具。本機端離線執行，支援加密 PDF 電子帳單自動解析、時序因果刷退對銷、月份多選統計、每日/月度消費圖表與交易明細全域檢索。

---

## 🌟 核心功能詳細介紹

### 1. 📊 總覽報表 (Overview Dashboard)
- **三大核心 KPI 數據卡片**：
  - **總消費金額**：精確計算所選月份與門檻條件下的實際刷卡總支出（自動扣除上期繳卡費負數）。
  - **總消費筆數 (可點擊卡片)**：整張卡片為原生點擊區塊，點擊任意處立即彈出 **Modal 明細視窗 (`st.dialog`)**，可快速瀏覽與核對所有納入統計的交易項目。
  - **單筆最高金額**：自動提取消費榜首金額與商家備註，字級隨商家名稱長度自動智慧縮放適應。
- **🗓️ 彈性月份篩選器 (Popover Month Filter)**：
  - 剛開啟應用時**預設只納入最近的一個月份**。
  - 點開選單提供 **「🔘 全選」** 與 **「✖️ 全取消」** 快捷按鈕，支援自訂複選任意月份後點擊 **「套用」** 批次更新。
- **📈 每日消費金額分布圖 (Plotly Bar Chart)**：
  - 採用離散類別 X 軸，**每一根長條柱精準對齊其交易日期**，自動去除無消費的空白日期。
  - 柱體上方標註純白高對比度數值（`JetBrains Mono / DIN Alternate` 設計字型）。
- **🗓️ 帳單月份消費總額圖**：
  - 各月份總花費依時間由舊至新**由左至右整齊排列**（選取 5 個月以下自動靠左排列，避免置中過寬）。
- **🔥 最高花費前 10 筆明細**：
  - 即時列出當前月份排行前 10 名的大額開銷。

---

### 2. 🔄 時序因果刷退自動對銷 (Time-Causality Refund Offsetting)
- **智能防呆比對演算法**：
  - 嚴格遵守「時序因果約束」：一筆刷退（$T_{refund}$）**只能抵銷發生在該刷退當日或之前（$T_{purchase} \le T_{refund}$）且時間最相近的原始消費**，絕對不會逆向抵銷未來的消費。
  - 支援跨月份帳單對銷（如 1 月份刷退成功對銷去年 12 月底的原始消費）。
  - 對銷後兩者自動自統計中剔除，不虛增總金額與交易筆數。

---

### 3. 📑 交易明細與搜尋 (Transaction Details & Search)
- **涵蓋所有金額大小**：此分頁**不受金額門檻過濾限制**，完整保留包含超商 35 元、停車費 60 元等所有小額日常消費。
- **月份切換**：下拉選單預設為「最新月份」，選單第一項為 **「全部」**，方便隨時切換全域檢索。
- **關鍵字搜尋**：支援輸入商家關鍵字（如：全聯、高鐵、露天），內建 Unicode NFKC 正規化比對。
- **📥 匯出 CSV**：一鍵將搜尋與篩選結果下載為 UTF-8 CSV 檔案。

---

### 4. 📁 帳單檔案管理與刷退稽核 (File Management & Audit)
- **PDF 掃描狀態報告**：即時檢視每個 PDF 檔案的解密狀態、解析筆數與歸屬帳單月份。
- **刷退對銷稽核清單**：透明列出所有被系統兩兩對銷的刷退項目與原始消費紀錄。

## 📥 如何放入帳單與填入密碼

### 步驟 1：放入 PDF 帳單檔案
1. 將銀行寄送的電子帳單 PDF 放置於專案根目錄的 **`./bills`** 資料夾中（預設路徑）。
2. 支援格式：任何以 `.pdf` 或 `.PDF` 結尾的檔案（檔名可為銀行原檔名如 `TSB_Creditcard_Estatement_202608.pdf`，或自訂檔名）。
3. *(自訂目錄)* 若您想將帳單存放在個人資料夾（如 `~/Documents/CreditCardBills` 或 `D:\MyBills`），可在左側邊欄的「📂 帳單 PDF 目錄」輸入框直接填入該資料夾路徑！

---

### 步驟 2：填入 PDF 解密密碼

您有兩種方式設定密碼（推薦使用方法 A）：

#### 方法 A（推薦：網頁側邊欄圖形介面設定）
1. 啟動應用後，在左側邊欄 **「⚙️ 設定與過濾」** 區域。
2. 在 **「PDF 解密密碼」** 欄位輸入您的密碼（通常為身分證字號，輸入時為遮蔽星號）。
3. 點擊 **「💾 儲存設定」**。設定會自動儲存至本機 `config.json`，且已受 `.gitignore` 保護不會外洩。

#### 方法 B（直接編輯 `config.json`）
複製 `config.example.json` 為 `config.json`，直接修改密碼欄位：
```json
{
  "bill_pdf_dir": "./bills",
  "pdf_password": "YOUR_ACTUAL_PASSWORD",
  "min_amount_filter": 500
}
```

## 🚀 雙擊一鍵啟動 (無需手動輸入指令)

### 🪟 Windows 使用者：
直接用滑鼠雙擊資料夾內的 **`run_dashboard.bat`**：
1. 程式會自動檢查 Python 環境、自動建立虛擬環境 (`venv`) 並安裝依賴套件。
2. 自動啟動並在 **預設瀏覽器（Edge / Chrome）中跳出儀表板**！

### 🍎 macOS 使用者：
直接用滑鼠雙擊資料夾內的 **`run_dashboard.command`**：
1. 自動開啟終端機並檢查環境。
2. 自動在 **預設瀏覽器（Safari / Chrome）中跳出儀表板**！

## 💻 命令列手動啟動 (開發者適用)

```bash
# 1. 建立並啟用 Python 虛擬環境
python3 -m venv venv
source venv/bin/activate       # macOS / Linux
# 或 venv\Scripts\activate     # Windows

# 2. 安裝必要套件
pip install -r requirements.txt

# 3. 執行啟動腳本
./run_dashboard.sh            # macOS / Linux
# 或 streamlit run app.py     # 通用指令
```

啟動後瀏覽器造訪 [http://localhost:8501](http://localhost:8501) 即可開始分析！
